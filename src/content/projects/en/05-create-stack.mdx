# create-stack: a real app, wired around your choices

## The product

**create-stack** is an npm CLI and web builder for creating full-stack applications. It starts from a working project instead of an empty template. You choose the shape of the project, and create-stack writes the files, wires the providers, checks the environment, and runs the validation before you make the first commit.

Next.js App Router and TanStack Start are available today. The generated project is TypeScript-first, MIT licensed, and ready to edit when the command finishes.

## The workflow

- **Choose the shape of the project**: select a framework, database, authentication, tRPC, mailer, monorepo, and optional capabilities.
- **Keep explicit choices explicit**: compatible omissions are completed with a reason you can see in the CLI or the web builder.
- **Start with a working app**: routing, styles, environment wiring, and a first screen are already connected.
- **Swap providers without a rewrite**: database, auth, email, and other capabilities use small interfaces, so replacing a provider stays local.
- **Keep the handoff readable**: create-stack removes what you did not select, runs TypeScript and Biome, and leaves ordinary files you can own.

![The build page: each choice updates the command and explains the resolved stack](../_assets/create-stack-builder.webp)

## The CLI and the web builder

The CLI and the builder use the same recommended stack. In the terminal, interactive prompts help you choose the pieces you want. Flags produce a non-interactive command that also works in scripts and automated environments.

The builder keeps the choices in the URL so a stack can be shared. Its resolution notes make dependencies visible instead of changing a choice silently. When you are ready, it gives you the exact command for pnpm, npm, yarn, or bun.

## What it generates

- **Frameworks**: Next.js App Router or TanStack Start.
- **Data and authentication**: Drizzle, Prisma, Convex, Better Auth, Clerk, or no provider when the project does not need one.
- **API and email**: tRPC plus Resend, Brevo, Amazon SES, or no mailer.
- **Workspace and capabilities**: a single app, Turborepo, or Nx, with optional object storage, cache, structured logging, analytics, background jobs, and error tracking.
- **Tooling**: Node.js, TypeScript, Tailwind CSS, and Biome.

## My role

I built create-stack as an MIT open-source project. I designed the composition engine, the provider boundaries, the CLI prompts, the web builder, and the checks that make the generated project ready for its first useful commit.
